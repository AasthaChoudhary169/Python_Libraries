Module 2: Pandas (Data Manipulation)

Pandas introduces DataFrames (structured tables with rows and columns), making data cleaning, filtering, and aggregation simple.

Core Operations (Click to Expand)

1. Handling Missing Data (`fillna`) +

💡 Why & When to Use

Real-world datasets have missing entries (`NaN`). Use fillna() to replace missing values with average numbers so models don't crash.

💻 Python Syntax

import pandas as pd
import numpy as np

# Sample dataset with missing value
data = {'Name': ['Alice', 'Bob', 'Charlie'],
        'Experience': [2.0, np.nan, 4.0]}
df = pd.DataFrame(data)

# Replace missing values with column mean
mean_exp = df['Experience'].mean()
df['Experience'] = df['Experience'].fillna(mean_exp)
print(df)

📊 Output Result

Name    Experience
Alice      2.0
Bob        3.0
Charlie   4.0
2. Aggregating Metrics (`groupby`) +

💡 Why & When to Use

Use groupby() to split your dataset into categories (e.g., Departments) and calculate average salaries or metrics per department.

💻 Python Syntax

import pandas as pd

data = {'Dept': ['DS', 'DS', 'Eng'],
        'Salary': [70000, 80000, 65000]}
df = pd.DataFrame(data)

# Calculate mean salary per Dept
result = df.groupby('Dept')['Salary'].mean()
print(result)

📊 Output Result

Dept
DS     75000
Eng    65000
