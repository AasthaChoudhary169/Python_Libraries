Module 3: Matplotlib (Data Visualization)

Matplotlib is a foundational Python visualization library used to create charts, plots, and customized visualizations for data analysis.

Core Concepts (Click to Expand)

1. Creating a Basic Line Plot+

💡 Why & When to Use

Use a line plot to show trends or changes in values over an ordered variable such as time.

💻 Python Syntax

import matplotlib.pyplot as plt

months = ["Jan", "Feb", "Mar", "Apr"]
sales = [120, 150, 180, 210]

plt.plot(months, sales, marker="o")
plt.title("Monthly Sales")
plt.xlabel("Month")
plt.ylabel("Sales")
plt.show()

📊 Output Result

A line chart showing sales increasing from January to April.
2. Bar Chart+

💡 Why & When to Use

Use bar charts to compare values across discrete categories such as products, departments, or regions.

💻 Python Syntax

import matplotlib.pyplot as plt

products = ["A", "B", "C", "D"]
sales = [45, 70, 55, 90]

plt.bar(products, sales)
plt.title("Product Sales")
plt.xlabel("Product")
plt.ylabel("Sales")
plt.show()

📊 Output Result

Four vertical bars comparing the sales of products A, B, C, and D.
3. Scatter Plot+

💡 Why & When to Use

Use scatter plots to examine the relationship or possible correlation between two numerical variables.

💻 Python Syntax

import matplotlib.pyplot as plt

hours = [1, 2, 3, 4, 5]
scores = [45, 52, 61, 70, 82]

plt.scatter(hours, scores)
plt.title("Study Hours vs Score")
plt.xlabel("Study Hours")
plt.ylabel("Score")
plt.show()

📊 Output Result

Points showing a positive relationship between study hours and scores.
4. Histogram+

💡 Why & When to Use

Use a histogram to understand the distribution of a numerical variable by grouping values into bins.

💻 Python Syntax

import matplotlib.pyplot as plt

ages = [21, 22, 22, 23, 24, 24, 24, 25, 26, 27, 28]

plt.hist(ages, bins=5)
plt.title("Age Distribution")
plt.xlabel("Age")
plt.ylabel("Frequency")
plt.show()

📊 Output Result

A frequency distribution showing how observations are spread across age ranges.
5. Pie Chart+

💡 Why & When to Use

Use a pie chart when you need to display simple part-to-whole proportions for a small number of categories.

💻 Python Syntax

import matplotlib.pyplot as plt

labels = ["Python", "SQL", "ML", "Power BI"]
values = [35, 25, 25, 15]

plt.pie(values, labels=labels, autopct="%1.1f%%")
plt.title("Skill Distribution")
plt.show()

📊 Output Result

A pie chart displaying the percentage contribution of each skill.
6. Subplots+

💡 Why & When to Use

Use subplots when multiple related charts need to be displayed together for comparison.

💻 Python Syntax

import matplotlib.pyplot as plt

fig, axes = plt.subplots(1, 2, figsize=(10, 4))

axes[0].plot([1, 2, 3], [10, 20, 15])
axes[0].set_title("Trend")

axes[1].bar(["A", "B", "C"], [30, 50, 40])
axes[1].set_title("Comparison")

plt.tight_layout()
plt.show()

📊 Output Result

Two related plots displayed in a single figure.
7. Customizing Labels, Legend and Grid+

💡 Why & When to Use

Use labels, legends, and grids to make visualizations easier to understand and communicate insights clearly.

💻 Python Syntax

import matplotlib.pyplot as plt

x = [1, 2, 3, 4]
y = [20, 35, 30, 50]

plt.plot(x, y, label="Revenue")
plt.xlabel("Quarter")
plt.ylabel("Revenue")
plt.title("Quarterly Revenue")
plt.legend()
plt.grid(True)
plt.show()

📊 Output Result

A labeled chart with a title, legend, and grid for easier interpretation.
8. Saving a Figure+

💡 Why & When to Use

Use savefig() when a visualization needs to be saved for a report, presentation, dashboard, or project.

💻 Python Syntax

import matplotlib.pyplot as plt

plt.plot([1, 2, 3], [10, 20, 15])
plt.title("Sample Plot")

plt.savefig("sales_plot.png", dpi=300, bbox_inches="tight")
plt.show()

📊 Output Result

A high-resolution PNG file named sales_plot.png is created.
