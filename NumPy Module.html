Module 1: NumPy (Numerical Python)

NumPy allows Python to perform high-speed mathematical operations on arrays up to 100x faster than standard Python lists.

Core Concepts (Click to Expand)

1. What is an N-Dimensional Array (`np.array`)? +

💡 Why & When to Use

Use np.array() when you need to store list-like numbers and perform calculations on all elements at once without writing slow for loops.

💻 Python Syntax

import numpy as np

# Create 1D array
scores = np.array([85, 90, 78, 92])

# Vectorized operation (adds 5 points to everyone)
updated_scores = scores + 5
print(updated_scores)

📊 Output Result

[90 95 83 97]
2. Reshaping Data Dimensions (`reshape`) +

💡 Why & When to Use

Use reshape() to change a flat list of values into a structured matrix with rows and columns (e.g., preparing image pixels or tabular feature matrices for ML models).

💻 Python Syntax

import numpy as np

# Create array from 1 to 6
arr = np.arange(1, 7)

# Convert 6 elements into 2 rows, 3 columns
matrix = arr.reshape(2, 3)
print(matrix)

📊 Output Result

[[1 2 3]
 [4 5 6]]
