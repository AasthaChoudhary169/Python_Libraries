Module 4: Seaborn (Statistical Visualization)

Seaborn is a statistical visualization library built on Matplotlib that makes attractive and informative data visualizations easier to create.

Core Concepts (Click to Expand)

1. Introduction to Seaborn+

💡 Why & When to Use

Use Seaborn when you want concise syntax and statistical plots that work naturally with Pandas DataFrames.

💻 Python Syntax

import seaborn as sns
import matplotlib.pyplot as plt

tips = sns.load_dataset("tips")

sns.scatterplot(data=tips, x="total_bill", y="tip")
plt.show()

📊 Output Result

A scatter plot showing the relationship between total bill and tip.
2. Count Plot+

💡 Why & When to Use

Use a count plot to show how many observations belong to each category.

💻 Python Syntax

import seaborn as sns
import matplotlib.pyplot as plt

tips = sns.load_dataset("tips")

sns.countplot(data=tips, x="day")
plt.title("Number of Records by Day")
plt.show()

📊 Output Result

Bars showing the number of observations for each day.
3. Bar Plot+

💡 Why & When to Use

Use a bar plot to compare an estimated numerical value across categories. Seaborn can also display confidence intervals.

💻 Python Syntax

import seaborn as sns
import matplotlib.pyplot as plt

tips = sns.load_dataset("tips")

sns.barplot(data=tips, x="day", y="total_bill")
plt.title("Average Bill by Day")
plt.show()

📊 Output Result

Bars comparing the average total bill across days.
4. Box Plot+

💡 Why & When to Use

Use a box plot to understand the distribution, median, quartiles, spread, and potential outliers of numerical data.

💻 Python Syntax

import seaborn as sns
import matplotlib.pyplot as plt

tips = sns.load_dataset("tips")

sns.boxplot(data=tips, x="day", y="total_bill")
plt.title("Bill Distribution by Day")
plt.show()

📊 Output Result

Box plots showing the distribution and possible outliers for each day.
5. Histogram and KDE Plot+

💡 Why & When to Use

Use a histogram with KDE to see both the frequency distribution and a smoothed estimate of the data distribution.

💻 Python Syntax

import seaborn as sns
import matplotlib.pyplot as plt

tips = sns.load_dataset("tips")

sns.histplot(data=tips, x="total_bill", kde=True)
plt.title("Total Bill Distribution")
plt.show()

📊 Output Result

A histogram with a KDE curve showing the shape of the bill distribution.
6. Scatter Plot with Hue+

💡 Why & When to Use

Use hue to divide observations into categories using different visual groups.

💻 Python Syntax

import seaborn as sns
import matplotlib.pyplot as plt

tips = sns.load_dataset("tips")

sns.scatterplot(
    data=tips,
    x="total_bill",
    y="tip",
    hue="sex"
)
plt.title("Bill vs Tip by Gender")
plt.show()

📊 Output Result

Points are visually grouped according to the sex category.
7. Heatmap and Correlation Matrix+

💡 Why & When to Use

Use a heatmap to display numerical relationships in matrix form. Correlation heatmaps are especially useful during EDA.

💻 Python Syntax

import seaborn as sns
import matplotlib.pyplot as plt

tips = sns.load_dataset("tips")
corr = tips.select_dtypes("number").corr()

sns.heatmap(corr, annot=True)
plt.title("Correlation Matrix")
plt.show()

📊 Output Result

A matrix where correlation values are displayed for pairs of numerical variables.
8. Pair Plot+

💡 Why & When to Use

Use a pair plot during exploratory data analysis to inspect relationships and distributions across multiple numerical variables at once.

💻 Python Syntax

import seaborn as sns
import matplotlib.pyplot as plt

tips = sns.load_dataset("tips")

sns.pairplot(
    tips,
    vars=["total_bill", "tip", "size"],
    hue="sex"
)
plt.show()

📊 Output Result

A grid of pairwise plots showing relationships and distributions between selected variables.
